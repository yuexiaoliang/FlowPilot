# FlowPilot 屏幕规格

本文件是 D0.3 的屏幕级实现契约。`S-01` 到 `S-10` 是给 Reviewer、Builder 和流程文档使用的稳定锚点，不是用户看到的标签或导航项。普通路径仍然使用自然语言/Markdown 和语义名称；内部 ID、cron、selector、Workflow DSL、原始日志和这些审阅锚点都不得成为用户操作前置条件。

屏幕不是十个永久顶层目的地。它们描述同一上下文工作区在 Simple、Execution、Inspection 三层中的可观察状态；上下文面板在触发条件结束后收回。屏幕规格引用 [D0.2 组件契约](COMPONENTS.md) 和 [D0.2 设计系统](DESIGN-SYSTEM.md)，流程细节见 [FLOWS.md](FLOWS.md)。

## 1. 共同规格

### 1.1 三层归属和信息边界

- **Simple** 负责表达意图、查看简洁理解、解决当前必要选择和读取最小结果。
- **Execution** 负责显示 Run 的有用里程碑、确切输入、确认、Human Takeover、暂停和安全恢复。
- **Inspection** 由 `检查详情` 或恢复所需证据进入，负责版本、来源、InputBundle、Flow、Run、证据和有界修复差异。
- 进入 Inspection 必须带有对象/陈述锚点；关闭后回到来源上下文并恢复触发焦点。它不是永久侧栏或运维 Dashboard。
- 普通 UI 不显示 Goal/Task/Source/InputBundle/Flow/Run 的内部 ID、cron、selector、Workflow node、模型 prompt、原始日志或未经脱敏的 Secret。必要事实只在 Inspection 的更深披露中可检查。

### 1.2 状态约定

每个屏幕都列出六种状态。`—` 表示该状态不属于屏幕语义，或屏幕在该状态下不渲染；不得为了完整矩阵生成空占位。

| 状态 | 屏幕级含义 |
| --- | --- |
| `idle` | 屏幕可见并等待当前上下文动作，或显示稳定的当前值。 |
| `loading` | 正在执行已说明的理解、连接、快照、校验、验证或详情加载。 |
| `success` | 本屏负责的条件已验证；不自动代表整个 Run 成功。 |
| `failure` | 已知、可解释且不可继续或需要选择的失败；保留输入和证据入口。 |
| `paused` | 等待确认、人工接管、重试窗口或安全状态判断。 |
| `disabled` | 因权限、策略、依赖或只读上下文不可操作；必须说明原因。 |

### 1.3 可访问性和动效基线

每个屏幕都必须遵守以下基线；屏幕专属差异在各自小节中再次明确：

- 焦点移动到新出现的上下文标题或第一项安全操作；关闭/解决后恢复到触发控件。确认卡与 Human Takeover 可以临时约束焦点，Inspection 不得无故抢焦点。
- 主要动作、选择和披露支持 `Tab`、`Shift+Tab`、`Enter`、`Space`、方向键和 `Escape` 的语义键盘路径；多行意图编辑器中的 `Enter` 不意外提交。
- 200% 缩放时正文、状态、主要操作和恢复路径仍可见；双栏可以重排为单栏，只有明确标注的结构化差异/哈希区域可横向滚动。
- `prefers-reduced-motion: reduce` 下取消非必要位移、缩放、循环动画和自动轮播；状态、焦点和证据不因减少动效而消失。
- 里程碑和终态使用单一 `aria-live="polite"` 短句；需要立即行动的安全暂停才使用一次 `assertive`。不播报每个内部 Step，也不在播报中泄漏 Secret、内部 ID 或原始日志。
- 颜色、图标、边框和文字共同表达状态，不能依赖颜色或动画；控件遵循 D0.2 的 44px 操作目标和对比度规则。

<a id="s-01-intent-home"></a>
## S-01 Intent Home / 意图主页

### 用户目标、层级与进入

- **用户目标/决策：** 用普通语言或 Markdown 表达要达到的结果、时间、数据、约束和确认/介入预期；决定是否开始分析。
- **三层归属：** Simple 主层；分析后的理解在 S-02；用户主动检查源文本/绑定时进入 S-08；不属于 Execution。
- **进入触发/前置：** 应用启动、回到首页、创建新 Goal/Task，或从 S-10 选择“创建新的意图”。没有 Source、账号或计划配置也可以进入；不能预先请求权限。

### 默认内容与操作

- **默认可见：** 面向结果的标题/提示、自然语言/Markdown 编辑器、当前未保存/已保存状态，以及唯一主要动作“分析我的意图”。已有工作入口只能作为轻量次要入口，不形成 Dashboard。
- **主要操作/语义名称：** 编辑意图、分析我的意图、保存/返回；建议中的 Source、目的地和时间显示语义名称，例如“我的行业学习仓库”“微信公众号”“每天早上 8 点”。
- **默认隐藏/渐进披露/检查入口：** 隐藏编译计划、内部绑定、规范化时间、Flow、日志和权限字段；分析成功后显示 S-02；存在底层事实时提供 `检查详情`，锚定源文本与当前理解。
- **D0.2 组件引用：** [COMPONENTS.md §3 意图编辑器](COMPONENTS.md#3-意图编辑器)、[§4 语义引用与建议](COMPONENTS.md#4-语义引用与建议)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | 文本可编辑；空白时只提供面向结果的引导，不显示配置字段或空 Source 面板。 |
| `loading` | 分析当前文本；保留文本、未保存标记和焦点，允许安全取消/返回。 |
| `success` | 意图输入通过边界校验，转到 S-02；不宣称 Run 成功。 |
| `failure` | 保留原文，说明无法分析的影响，提供重试或改写；不自动替换用户句子。 |
| `paused` | —；运行时暂停由 S-05/S-06 显示。 |
| `disabled` | 仅在历史源文本只读或当前策略保护时使用，显示原因和可查看路径。 |

- **退出/结果/恢复：** 分析成功进入 S-02；取消回到原上下文并保留未保存文本；分析失败留在本屏；用户选择已有工作进入 S-10。任何退出不改变用户源文本或 Source 权限。

### 可访问性与安全约束

- **焦点/键盘：** 文本区有标签；`Tab` 进入编辑器和主要动作；多行 `Enter` 保持换行；语义建议用方向键/`Enter`，`Escape` 关闭并恢复编辑焦点。
- **200% 缩放：** 编辑器和主要动作单列重排，正文不裁切；无横向滚动依赖。
- **减少动态效果：** 分析按钮只做短暂状态变化，取消面板位移；不使用自动轮播或闪烁。
- **Live region：** 只播报“正在分析/理解已更新/无法分析”等短句，不播报整篇文本。
- **Source：** 自然语言只表达候选语义，不授予文件/仓库访问；Source 授权由 S-03 明确完成。
- **InputBundle：** —；本屏不能显示或编辑本次不可变输入。
- **确认：** —；不可逆动作确认由 S-06 确认模式完成。
- **安全/Secret：** 不收集或显示密码、cookie、session、token、原始页面内容；网页/Source 文本是不可信输入，不得扩大权限。

- **流程锚点：** [G-01](FLOWS.md#g-01-intent-to-understanding)、[B-02](FLOWS.md#b-02-语义歧义)、[B-10](FLOWS.md#b-10-已有-goaltask-连续性)。

<a id="s-02-ai-understanding-review"></a>
## S-02 AI Understanding Review / 理解审阅

### 用户目标、层级与进入

- **用户目标/决策：** 判断 FlowPilot 对时间、数据、操作、无匹配策略和确认/介入的理解是否与意图一致；只在有实质歧义时作选择。
- **三层归属：** Simple 主层；必要选择以临时 Simple 上下文打开 S-03 或歧义处理器；完整计划和绑定在 S-08；不属于 Execution。
- **进入触发/前置：** S-01 分析完成且理解通过结构化校验；已有 Goal/Task 从 S-10 打开时也可进入。源文本变化后旧理解标记过期，必须重新分析。

### 默认内容与操作

- **默认可见：** “我的理解”摘要：时间/时区、数据 Source 语义名、操作/目的地、没有匹配内容时的策略、发布前确认/人工介入。每项只显示当前决策所需的信息。
- **主要操作/语义名称：** 继续准备输入、解决“数据/操作”中的问题、编辑意图、检查详情；不要求填写计划字段。
- **默认隐藏/渐进披露/检查入口：** 隐藏完整 GoalPlan/TaskPlan、实体引用、规范化 schedule、Flow 和 provider 信息；用户可从具体理解项进入 S-08。
- **D0.2 组件引用：** [COMPONENTS.md §5 理解审阅](COMPONENTS.md#5-理解审阅)、[§4 语义引用与建议](COMPONENTS.md#4-语义引用与建议)、必要时 [§6 歧义处理器](COMPONENTS.md#6-歧义处理器)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | 显示稳定摘要；不填充用户未表达的默认值。 |
| `loading` | 显示正在理解的对象；旧摘要标为过期但不与新文本混用。 |
| `success` | 摘要通过校验，可进入 Source resolution 或 S-04；仍不是 Run 成功。 |
| `failure` | 说明无法理解的影响；把需要选择的部分交给歧义处理器，不猜测。 |
| `paused` | —；运行时暂停由 S-05/S-06 承担。 |
| `disabled` | 依赖缺失或历史版本只读时显示原因；源文本和旧理解仍可查看。 |

- **退出/结果/恢复：** 无歧义时进入 G-03 的 Source resolution；缺失授权进入 S-03；实质歧义停留在上下文选择；编辑回 S-01；失败重试不丢源文本。

### 可访问性与安全约束

- **焦点/键盘：** 摘要按标题/描述列表读取；当前问题焦点进入对应操作；选择列表支持方向键、`Space`/`Enter` 和 `Escape`。
- **200% 缩放：** 摘要从多列重排为单列，长解释保持可读行宽；不要求横向滚动。
- **减少动态效果：** 新摘要即时替换或低幅透明度变化；不用动画暗示“AI 已完成”作为唯一证据。
- **Live region：** 播报理解更新和实质阻塞一次；不播报隐藏的计划或内部引用。
- **Source：** 只显示语义 Source 和缺失/已授权状态；未授权时转 S-03，不把名称当权限。
- **InputBundle：** —；只能在 S-04 检查本次具体输入。
- **确认：** 只显示“需要发布前确认”的语义摘要，不在这里提前确认不可逆动作。
- **安全/Secret：** AI/编译结果为不可信输入，必须结构化校验；Secret、session 和未经必要脱敏的远程内容不进入普通摘要。

- **流程锚点：** [G-01](FLOWS.md#g-01-intent-to-understanding)、[G-02](FLOWS.md#g-02-understanding-and-semantic-resolution)、[B-02](FLOWS.md#b-02-语义歧义)。

<a id="s-03-contextual-source-connection"></a>
## S-03 Contextual Source Connection / 上下文式 Source 连接

### 用户目标、层级与进入

- **用户目标/决策：** 明确授权满足当前意图所需的本地文件夹/仓库范围，或拒绝/改选；理解授权用途和最小权限。
- **三层归属：** Simple 的临时上下文主层；S-04 前可作为 Execution 预检卡；授权范围、版本和快照在 S-08 检查；不是永久 Source 管理首页。
- **进入触发/前置：** S-02 发现没有兼容且已授权的 Source，或现有 Source 不满足范围/能力；打开系统选择器前必须显示理由和请求范围。

### 默认内容与操作

- **默认可见：** 语义 Source 名称、为什么需要访问、任务所需能力、请求的文件夹/仓库范围、默认只读说明，以及“选择范围/取消”。
- **主要操作/语义名称：** 选择行业学习仓库、使用此文件夹、取消连接、重新选择；不要求输入 Source ID 或路径 DSL。
- **默认隐藏/渐进披露/检查入口：** 隐藏内部 Source ID、provider 元数据、完整权限记录、快照/哈希；连接成功后只保留语义名称与范围摘要，详细权限进入 S-08。
- **D0.2 组件引用：** [COMPONENTS.md §7 Source 连接与权限选择器](COMPONENTS.md#7-source-连接与权限选择器)、[§4 语义引用与建议](COMPONENTS.md#4-语义引用与建议)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | 显示请求理由、范围和连接操作；不自动弹出系统选择器。 |
| `loading` | 正在打开选择器或检查授权，防止重复提交，允许取消。 |
| `success` | 授权范围已保存且 Source 检查通过；返回 S-02/S-04，但仍必须执行 Source resolution 和 snapshot。 |
| `failure` | 用户拒绝、范围不匹配、Source 不可用或检查失败；说明影响并允许改选/重试/停止。 |
| `paused` | —；授权等待不冒充运行时 Human Takeover。 |
| `disabled` | 策略/平台不允许该范围或历史对象只读；显示原因与检查入口。 |

- **退出/结果/恢复：** 成功回到 S-02 的数据项并开始 G-03；拒绝/取消回到 S-02 的未解决状态；范围问题不扩大权限，改选仍从系统选择器重新授权。

### 可访问性与安全约束

- **焦点/键盘：** 连接说明、范围、主/次按钮有序；系统选择器返回后恢复到触发按钮；拒绝和错误焦点到原因。
- **200% 缩放：** 范围和授权说明单列显示；路径长文本可换行，不依赖横向滚动。
- **减少动态效果：** 选择器打开/关闭不依赖位移动画；授权结果用明确文本。
- **Live region：** 播报“正在检查授权/已连接/未授权”一次，不播报完整路径或内容。
- **Source：** 默认只读、显式 scoped root、least privilege；自然语言不能扩大本地文件系统访问。
- **InputBundle：** —；连接成功不是 InputBundle 创建，必须进入 Source resolution/selection/snapshot。
- **确认：** —；权限授权不是不可逆发布确认，二者不可合并。
- **安全/Secret：** 不显示 Secret、cookie、session、token；Source 内容只在任务需要且经过脱敏时进入后续理解/执行。

- **流程锚点：** [G-03](FLOWS.md#g-03-source-resolution-and-immutable-input)、[B-01](FLOWS.md#b-01-source-缺失拒绝或范围问题)。

<a id="s-04-input-preview"></a>
## S-04 Input Preview / 输入预览

### 用户目标、层级与进入

- **用户目标/决策：** 检查本次 Run 将使用的确切文章/文件、标题/正文/封面等输入，以及 Source 语义名称和选择结果；决定继续、返回或重新选择。
- **三层归属：** Execution 主层；Simple 只保留“已准备输入”摘要；S-08 显示不可变 provenance；不替代 Source picker。
- **进入触发/前置：** S-02 理解完成且 Source resolution、selection、binding、snapshot 和 required input 校验完成；无匹配或输入失效时不能进入成功预览。

### 默认内容与操作

- **默认可见：** 本次输入的可读名称、关键字段/正文摘要/封面预览、Source 语义名称、快照/版本摘要、缺失项（如有）和“继续准备运行/返回重新选择”。
- **主要操作/语义名称：** 展开文章内容、查看封面、继续运行、重新选择输入、返回；不显示原始哈希/内部 bundle 结构。
- **默认隐藏/渐进披露/检查入口：** 详细选中路径、content hash、Git SHA、完整 InputBundle 字段进入 S-08；`检查详情` 锚定本次不可变 bundle。
- **D0.2 组件引用：** [COMPONENTS.md §8 InputBundle 预览](COMPONENTS.md#8-inputbundle-预览)、[§12 结果摘要与 `检查详情`](COMPONENTS.md#12-结果摘要与-检查详情)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | —；没有可检查 bundle 不显示空预览。 |
| `loading` | 显示正在解析、选择、冻结和校验的对象；不能静默换入新内容。 |
| `success` | 本次 InputBundle 已创建且不可变，继续进入 S-05；不代表目的地动作成功。 |
| `failure` | 无匹配、缺失必需输入、选择歧义、快照失败或内容过期；提供重选、按策略跳过/失败或停止。 |
| `paused` | policy 要求用户审阅输入时等待继续/返回；不与发布确认合并。 |
| `disabled` | Source 未授权、权限不足或 bundle 被历史 Run 锁定；说明原因与检查入口。 |

- **退出/结果/恢复：** 继续进入 G-04/S-05；返回到 S-02 或 S-03；输入过期必须重新 snapshot 并生成新的 Run，不更新旧 bundle。

### 可访问性与安全约束

- **焦点/键盘：** 输入字段有名称、来源和必需性；预览展开/收起和继续/返回可键盘完成，错误焦点指向缺失字段。
- **200% 缩放：** 预览内容、字段和主要动作单列重排；图片可缩放但不以图片替代文字。
- **减少动态效果：** 图片/内容展开即时或短透明度变化；不自动播放媒体或轮播内容。
- **Live region：** 播报“输入已准备/缺少必需输入/输入已过期”一次，不播报大段正文。
- **Source：** 只引用完成授权的 scoped Source；预览显示语义名和版本摘要，不能重新读取范围外内容。
- **InputBundle：** 必须来自执行前 snapshot；进入 S-05 后不可静默变化，改动只能创建新 bundle/Run。
- **确认：** 输入审阅不是不可逆发布确认；发布确认在 S-06 确认模式。
- **安全/Secret：** 预览不显示 Secret、session、cookie 或未脱敏页面内容；封面/正文只显示当前任务需要的内容。

- **流程锚点：** [G-03](FLOWS.md#g-03-source-resolution-and-immutable-input)、[G-04](FLOWS.md#g-04-input-preview-to-run)、[B-03](FLOWS.md#b-03-输入无匹配缺失校验或过期)。

<a id="s-05-execution"></a>
## S-05 Execution / 执行

### 用户目标、层级与进入

- **用户目标/决策：** 知道 Run 正在做什么、下一项有意义的里程碑是什么，以及是否需要确认、接管、取消或安全恢复。
- **三层归属：** Execution 主层；结果回到 S-07；时间线、Step evidence、版本和日志从 S-08 检查；不显示运维 Dashboard。
- **进入触发/前置：** S-04 继续后，Source resolution 和不可变 InputBundle 已完成；Task/Goal policy 允许启动 Run。

### 默认内容与操作

- **默认可见：** 当前里程碑（如“正在准备输入”“正在打开发布平台”“正在验证结果”）、当前目标语义名、必要的确切输入摘要、取消/检查入口及当前可操作的下一步。
- **主要操作/语义名称：** 取消运行、等待/继续（仅策略允许）、确认发布或接管（仅在对应屏幕族出现）、检查详情；不显示每一个内部 Step。
- **默认隐藏/渐进披露/检查入口：** 隐藏持续滚动日志、selector、目标描述符、模型请求、堆栈和低层计时；失败或用户选择 `检查详情` 时进入 S-08。
- **D0.2 组件引用：** [COMPONENTS.md §10 执行进度与恢复](COMPONENTS.md#10-执行进度与恢复)、[§12 结果摘要与 `检查详情`](COMPONENTS.md#12-结果摘要与-检查详情)、必要时 [§11 Human Takeover](COMPONENTS.md#11-human-takeover)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | Run 已接收但尚未执行，显示最小“准备中”；不显示空时间线。 |
| `loading` | 显示确定性里程碑和安全取消；不暴露每个内部事件。 |
| `success` | 仅后置条件/目标结果验证后转 S-07；不在验证前显示成功。 |
| `failure` | 显示类型化但面向人的影响、最后成功检查点、检查入口和允许的恢复。 |
| `paused` | 明确是等待确认、Human Takeover、重试窗口或安全暂停；不自动继续未知状态。 |
| `disabled` | 取消窗口关闭、只能查看或恢复被策略禁止时，禁用对应动作并保留状态说明。 |

- **退出/结果/恢复：** 进入 S-06 确认/接管、S-07 终态或 S-08 证据；取消产生明确 `CANCELLED` 结果；恢复必须回到已知检查点、重新 snapshot（若安全要求）并重新验证。

### 可访问性与安全约束

- **焦点/键盘：** 状态标题和当前动作可读；取消、检查、确认、接管和恢复有明确键盘顺序；暂停/失败焦点到原因和第一项安全动作。
- **200% 缩放：** 状态、当前输入、主要动作单列可见；不依赖时间线横向滚动。
- **减少动态效果：** 进度不使用持续位移/闪烁；里程碑可以即时替换，旋转指示器不是唯一反馈。
- **Live region：** 每个用户可理解里程碑只播报一次；安全暂停或未知状态必要时一次 `assertive`。
- **Source：** Run 只使用已解析并授权的 Source snapshot，不在执行中静默重新读取变化内容。
- **InputBundle：** 绑定本次不可变 bundle；重试不能悄悄使用新数据。
- **确认：** 不可逆边界前转 S-06 确认模式；确认后仍需动作和后置条件验证。
- **安全/Secret：** BrowserDriver/隔离浏览器负责网页操作；Secret 不进入普通状态、日志、截图或 prompt；CAPTCHA/MFA/安全挑战转 Human Takeover。

- **流程锚点：** [G-04](FLOWS.md#g-04-input-preview-to-run)、[G-05](FLOWS.md#g-05-run-to-confirmation-or-human-takeover)、[G-06](FLOWS.md#g-06-verified-result)、[B-05](FLOWS.md#b-05-human-takeover)、[B-06](FLOWS.md#b-06-类型化失败与安全恢复)、[B-07](FLOWS.md#b-07-终态分支)。

<a id="s-06-confirmation--human-takeover-屏幕族"></a>
## S-06 Confirmation / Human Takeover 屏幕族

S-06 是同一 Execution 上下文中的两个严格不同模式，不能合并为通用警告框：

### A. Confirmation 模式

- **用户目标/决策：** 在不可逆动作前确认或取消“将对哪个目的地执行什么动作”，而不是认证或完成安全挑战。
- **三层归属：** Execution 临时上下文；确认事件和策略在 S-08；关闭回 S-05。
- **进入触发/前置：** S-05 到达 confirmation policy 的不可逆边界，且目的地、InputBundle、去重/幂等检查通过。
- **默认可见：** 明确动词、目的地语义名、确切输入摘要、不可逆影响、取消和确认两个显式动作。
- **主要操作/语义名称：** 取消发布、确认发布；关闭、遮罩点击和 `Escape` 都不算确认。
- **默认隐藏/渐进披露/检查入口：** 隐藏原始计划、内部账号引用、日志和 selector；`检查详情` 查看确认策略、事件、输入版本。
- **D0.2 组件引用：** [COMPONENTS.md §9 确认卡](COMPONENTS.md#9-确认卡)、[§8 InputBundle 预览](COMPONENTS.md#8-inputbundle-预览)。

### B. Human Takeover 模式

- **用户目标/决策：** 在真实、隔离的浏览器上下文中完成登录、扫码、同意或安全判断，再明确交还控制；不把人工操作当成自动成功。
- **三层归属：** Execution 临时上下文；接管和重新验证证据在 S-08；关闭/停止留在 S-05 的暂停状态。
- **进入触发/前置：** runtime 检测 `LOGIN_REQUIRED`、`QR_REQUIRED`、`CAPTCHA`、`MFA_REQUIRED`、`SECURITY_CHALLENGE`、`ACCOUNT_WARNING`、同意流程或未知插页；必须先暂停自动化。
- **默认可见：** 暂停原因、用户要做什么、真实页面上下文、安全说明、“交还控制”和停止；明确 FlowPilot 交还后将重新 snapshot/验证什么。
- **主要操作/语义名称：** 打开安全页面、完成登录/扫码/判断、交还控制、停止运行；不提供绕过按钮。
- **默认隐藏/渐进披露/检查入口：** 隐藏 session/cookie、原始网络数据和模型上下文；`检查详情` 查看 takeover 事件、重新验证证据和失败原因。
- **D0.2 组件引用：** [COMPONENTS.md §11 Human Takeover](COMPONENTS.md#11-human-takeover)、[§10 执行进度与恢复](COMPONENTS.md#10-执行进度与恢复)。

### S-06 状态、退出与恢复及安全约束

| 状态 | Confirmation 模式 | Human Takeover 模式 |
| --- | --- | --- |
| `idle` | 等待确认/取消，显示仍有效的输入和目的地。 | —；无风险时不渲染接管框架。 |
| `loading` | 复核 InputBundle、目的地、policy 和幂等边界。 | 正在打开隔离浏览上下文或整理脱敏状态。 |
| `success` | 只表示用户决定事件已记录，回 S-05 执行动作；不表示发布成功。 | 只表示已交还控制，立即进入重新验证；不表示认证/动作成功。 |
| `failure` | 输入/目的地/权限在确认前变化，拒绝确认并回 S-04/S-03 或停止。 | 交还后状态未知/验证失败/安全策略不允许恢复，保持暂停或停止。 |
| `paused` | —；等待用户本身属于 `idle`，运行暂停由 S-05 显示。 | 等待登录、扫码、MFA/安全挑战、同意或人工判断。 |
| `disabled` | policy 不允许动作、Run 已终止或缺少确认权限；说明原因。 | 不允许安全接管或要求停止；无绕过操作。 |

- **退出/结果/恢复：** Confirmation 确认进入 S-05，只有用户显式选择“取消发布”才进入 S-07 的 `CANCELLED`；关闭、遮罩点击或 `Escape` 只退回 S-05 的待决定暂停状态，不确认、不执行、也不自动终止 Run。Human Takeover 交还必须重新 snapshot、验证已知安全状态后才回 S-05，未知状态只能停止/继续人工处理。

### S-06 可访问性与安全约束

- **可访问性：** 焦点进入模式标题/第一项安全动作；Confirmation 使用 dialog 语义并约束焦点，Takeover 不把辅助技术焦点强行注入不可信网页；两者均支持键盘、200% 单列重排、reduced-motion 即时转场；模式切换和暂停只播报一次。
- **Source/InputBundle/确认/安全/Secret：** Confirmation 绑定已冻结 InputBundle 和已解析 Source，不能确认新读取的数据；Takeover 不扩大 Source 权限；Confirmation 是不可逆动作决定，Takeover 是人工安全介入，二者事件分开记录；Secret 留在受保护页面，不进入 UI、日志、截图或 AI prompt，禁止 CAPTCHA/MFA/stealth/fingerprint bypass。

- **流程锚点：** [G-05](FLOWS.md#g-05-run-to-confirmation-or-human-takeover)、[B-04](FLOWS.md#b-04-确认取消)、[B-05](FLOWS.md#b-05-human-takeover)。

<a id="s-07-result"></a>
## S-07 Result / 结果

### 用户目标、层级与进入

- **用户目标/决策：** 明白这一次发生了什么、是否真正达到目标、是否跳过/取消/失败，以及下一步是否需要操作。
- **三层归属：** Simple 终态主层；从 S-05 Execution 收尾进入；结果证据和版本通过 S-08 检查；不建立结果 Dashboard。
- **进入触发/前置：** Run 完成后置条件验证并进入 `SUCCEEDED`、`SKIPPED`、`FAILED` 或 `CANCELLED`；验证未完成时留在 S-05。

### 默认内容与操作

- **默认可见：** 最小结果句、目标/目的地语义名、成功/跳过/失败/取消的影响、必要下一步和 `检查详情`。
- **主要操作/语义名称：** 检查详情、重试/重新运行（仅 policy 允许）、返回意图、处理失败；成功态不展示无关指标。
- **默认隐藏/渐进披露/检查入口：** 隐藏时间线、Step evidence、Source snapshot、InputBundle、Flow revision、原始日志；从结果陈述进入 S-08。
- **D0.2 组件引用：** [COMPONENTS.md §12 结果摘要与 `检查详情`](COMPONENTS.md#12-结果摘要与-检查详情)、[§10 执行进度与恢复](COMPONENTS.md#10-执行进度与恢复)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | —；无终态不显示结果卡片。 |
| `loading` | 显示正在验证结果，不提前显示成功/失败。 |
| `success` | 只显示后置条件已验证的最小成功结果和检查入口。 |
| `failure` | 显示失败/取消影响、最后已知状态、允许的恢复和检查入口。 |
| `paused` | —；未终态暂停由 S-05/S-06 显示。 |
| `disabled` | 结果可见但证据入口因权限/脱敏策略不可用，说明原因。 |

- **退出/结果/恢复：** 成功可进入 S-08 检查；跳过只说明 `SKIPPED` 原因，不呈现成功样式；失败进入 S-05 恢复或 S-09 修复评审；取消保留 Run 证据，不自动重试。

### 可访问性与安全约束

- **焦点/键盘：** 结果标题、状态、下一步和 `检查详情` 有序可读；打开/关闭 Inspector 恢复焦点。
- **200% 缩放：** 结果句和主要动作单列、可读；不以图表或颜色承载结果。
- **减少动态效果：** 终态即时显示或短透明度变化；不庆祝式动画遮挡结果。
- **Live region：** 一次播报具体“已发布/未发布/已跳过/已取消/失败”及必要影响，不能只播报“完成”。
- **Source：** 结果关联本次 Run 的 Source snapshot，不切换到最新 Source 内容。
- **InputBundle：** 结果说明使用的本次不可变 bundle；详细 provenance 在 S-08。
- **确认：** 结果只显示确认事件是否发生及其影响；确认不能替代成功验证。
- **安全/Secret：** 结果摘要不包含 Secret、session、原始网页内容或未脱敏日志；远程页面声称成功必须经过后置条件验证。

- **流程锚点：** [G-06](FLOWS.md#g-06-verified-result)、[G-07](FLOWS.md#g-07-inspect-details)、[B-07](FLOWS.md#b-07-终态分支)。

### `SKIPPED` 特殊规则

`SKIPPED` 是合法终态但不是 `success`。例如“今天没有匹配内容，未发布”使用中性信息样式和明确原因；不能推进 consumption/cursor 到错误边界，也不能误报发布成功。

<a id="s-08-inspector-professional-detail"></a>
## S-08 Inspector / professional detail

### 用户目标、层级与进入

- **用户目标/决策：** 检查当前理解、授权和快照、不可变 InputBundle、Flow/Run 版本、证据、确认/接管事件或失败原因，以理解/恢复/审计当前陈述。
- **三层归属：** Inspection 主层；从 S-02、S-04、S-05、S-07、S-09 或 S-10 的具体 `检查详情` 进入；关闭返回原层，不是永久导航。
- **进入触发/前置：** 用户主动检查，或失败/恢复必须显示特定证据；必须带有确切对象/Run/版本锚点。

### 默认内容与操作

- **默认可见：** 与入口相关的第一分区：源文本与理解、Source/授权、InputBundle、Flow/Run、证据或修复差异；从可读事实开始。
- **主要操作/语义名称：** 展开来源、查看输入、查看验证证据、查看确认/接管事件、返回、关闭；专业用户可按需展开技术详情。
- **默认隐藏/渐进披露/检查入口：** 默认折叠全量计划、内部 ID、规范化时间、路径/hash、原始事件/日志和模型信息；只在明确展开且已脱敏时显示。
- **D0.2 组件引用：** [COMPONENTS.md §13 Inspector 外壳与分区](COMPONENTS.md#13-inspector-外壳与分区)、[§14 证据查看器](COMPONENTS.md#14-证据查看器)、[§15 修复差异](COMPONENTS.md#15-修复差异)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | —；未打开时无空侧栏/空诊断页。 |
| `loading` | 显示正在加载哪个对象/版本，先保留来源锚点。 |
| `success` | 提供与入口相关的结构化事实、证据和版本关系，深层按需展开。 |
| `failure` | 说明详情不可加载、版本不存在或被脱敏；不显示半真半假的字段。 |
| `paused` | 当前 Run 暂停时突出原因、最后成功检查点和允许恢复；打开详情不自动继续。 |
| `disabled` | 某分区因权限/脱敏策略不可查看，说明原因和可用替代摘要。 |

- **退出/结果/恢复：** 关闭回 S-02/S-04/S-05/S-07/S-09/S-10 并恢复焦点；证据不足时回到失败/暂停而不自动恢复；版本关系始终绑定原 Run，不更新到最新数据。

### 可访问性与安全约束

- **焦点/键盘：** 外壳有标题、锚点、关闭/返回；分区以可折叠标题和 `aria-expanded` 关联，隐藏技术详情不进入普通 Tab 顺序。
- **200% 缩放：** 侧栏转同上下文面板/单列；结构化表格有标题，差异/hash 仅在明确标注区域横向滚动。
- **减少动态效果：** 分区即时展开/收起或低幅透明度变化；不使用自动刷新、滚动日志和自动跳转。
- **Live region：** 只播报分区加载、错误、暂停和修复校验变化；不把原始事件逐条播报。
- **Source：** 展示 exact snapshot/权限的检查事实但不改变授权；不能静默重新读取 Source。
- **InputBundle：** 显示本次 immutable bundle 与 provenance，不能将新 bundle 覆盖旧 Run。
- **确认：** 显示确认策略和事件，但不能在 Inspector 中伪造或撤销已发生的不可逆动作。
- **安全/Secret：** 技术字段、截图和日志必须脱敏；Secret、cookie、session 不显示/复制到普通剪贴板；远程内容仍是不可信输入。

- **流程锚点：** [G-07](FLOWS.md#g-07-inspect-details)、[G-08](FLOWS.md#g-08-close-inspection-and-return)、[B-08](FLOWS.md#b-08-inspection)、[B-09](FLOWS.md#b-09-repair-diff)。

<a id="s-09-repair-diff"></a>
## S-09 Repair Diff / 修复差异

### 用户目标、层级与进入

- **用户目标/决策：** 理解局部修复解决什么失败、旧/新行为的最小差异、验证与安全影响，并决定接受、保留旧版本或停止。
- **三层归属：** Inspection 主层；必要时从 S-05 的可恢复失败卡进入临时上下文；不占据黄金路径，也不成为完整 Workflow 编辑器。
- **进入触发/前置：** Repair proposal 已通过 schema/policy 边界检查，且行为变化需要用户评审、跨策略边界或用户主动要求比较；旧 Flow revision 仍保留。

### 默认内容与操作

- **默认可见：** 失败影响、最后成功检查点、受影响目标、旧/新可读路线或行为的最小差异、试运行/校验状态和用户影响。
- **主要操作/语义名称：** 接受此修复、保留旧版本、返回失败、检查详情；按钮不使用“自动修好”或暗示绕过安全。
- **默认隐藏/渐进披露/检查入口：** 隐藏完整 Workflow DSL、selector、模型 prompt、无关步骤和原始日志；可在 S-08 展开差异证据。
- **D0.2 组件引用：** [COMPONENTS.md §15 修复差异](COMPONENTS.md#15-修复差异)、[§14 证据查看器](COMPONENTS.md#14-证据查看器)、[§10 执行进度与恢复](COMPONENTS.md#10-执行进度与恢复)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | —；无需要比较的提议不渲染差异。 |
| `loading` | 正在校验/生成有界差异，未经校验的候选不可接受。 |
| `success` | 仅表示 candidate 已通过 schema/policy、bounded trial 与预期状态验证，且证据可查看；接受仍需用户决定，此时尚未保存新 revision。 |
| `failure` | 提议无效、不安全、超出范围或试运行失败；保留旧 Flow，提供停止/返回/重新检查。 |
| `paused` | 等待用户评审或安全边界决定；不自动接受或覆盖旧版本。 |
| `disabled` | hard-stop、权限或证据不足时禁用接受，仍可查看失败原因并保留旧版本。 |

- **退出/结果/恢复：** Candidate 先通过 schema/policy 校验、bounded trial 和预期状态验证；用户检查这些证据并显式接受后，才保存新的 immutable Flow revision，并让后续 Run 使用它。拒绝/关闭、试运行失败或验证未达到预期状态时不创建新 revision，并回到 S-05/S-08，旧 revision 不变；未知安全状态只能停止。

### 可访问性与安全约束

- **焦点/键盘：** 旧行为/新行为标题明确，差异可用文字读出；接受/保留旧版本/取消有后果说明，关闭恢复到失败卡。
- **200% 缩放：** 差异从并排重排为上下对照；只有结构化差异区域可横向滚动，颜色/删除线不是唯一线索。
- **减少动态效果：** 差异即时显现，不使用跳转/闪烁强调改动。
- **Live region：** 只播报校验、试运行和安全阻塞状态一次；未知状态不播报为成功。
- **Source：** 修复只能作用于当前 Flow/Run 的已知范围，不能借修复扩大 Source 权限。
- **InputBundle：** 修复不得修改已执行 Run 的 bundle；新行为若需新输入，必须明确创建新 Run/重新 snapshot。
- **确认：** 若修复改变不可逆动作策略，必须回到适用的 S-06 Confirmation；修复接受不等于发布确认。
- **安全/Secret：** 不在差异中显示 Secret/session/原始网页凭证；页面内容不能改变 hard-stop policy，禁止安全绕过。

- **流程锚点：** [B-06](FLOWS.md#b-06-类型化失败与安全恢复)、[B-09](FLOWS.md#b-09-repair-diff)。

<a id="s-10-existing-goaltask-已有-goaltask-查看页"></a>
## S-10 Existing Goal/Task / 已有 Goal/Task 查看页

### 用户目标、层级与进入

- **用户目标/决策：** 查看并继续编辑已有 Goal/Task 的人类源文本，理解当前语义和最近结果；决定重新分析、运行、检查或回到 Intent Home。
- **三层归属：** Simple 主层；理解/Source/输入/运行详情分别进入 S-02/S-03/S-04/S-05，专业事实进入 S-08；不把编译配置当作编辑页。
- **进入触发/前置：** 用户从最近工作/结果或语义名称打开已有 Goal/Task；必须加载人类可读源文本和其当前理解版本。

### 默认内容与操作

- **默认可见：** 源文本、语义名称、当前简洁理解/过期提示、最近结果摘要、一个主要下一步（编辑并重新分析、继续运行或检查详情）。
- **主要操作/语义名称：** 编辑意图、重新分析、继续运行、查看结果、检查详情、返回 Intent Home；不能直接编辑机器计划。
- **默认隐藏/渐进披露/检查入口：** 隐藏旧/新 revision、内部实体引用、Flow、Run 时间线、Source 快照和原始日志；从相关摘要进入 S-08。
- **D0.2 组件引用：** [COMPONENTS.md §3 意图编辑器](COMPONENTS.md#3-意图编辑器)、[§5 理解审阅](COMPONENTS.md#5-理解审阅)、[§12 结果摘要与 `检查详情`](COMPONENTS.md#12-结果摘要与-检查详情)。

### 状态、退出与恢复

| 状态 | 行为 |
| --- | --- |
| `idle` | 显示源文本和当前理解，可继续编辑/检查。 |
| `loading` | 正在加载源文本/当前理解/最近结果；保留来源上下文，避免跳到空配置页。 |
| `success` | 源文本已加载且当前理解有效；用户可继续到 S-02/S-05。 |
| `failure` | 源文本/版本/结果不可用时说明影响，保留可查看摘要和安全返回；不凭空重建。 |
| `paused` | —；Run 暂停显示在 S-05/S-06，打开已有工作不解除暂停。 |
| `disabled` | 受保护历史 revision 只读时禁用编辑，仍允许查看和检查原因。 |

- **退出/结果/恢复：** 编辑后回 S-01/S-02 并生成新的理解 revision；继续运行遵循 G-03/G-04 重新解析 Source 和生成 bundle；关闭/返回保留未保存文本；不可静默把旧计划应用于新文本。

### 可访问性与安全约束

- **焦点/键盘：** 打开后焦点到源文本标题/编辑器；编辑、重新分析、检查、返回均可键盘完成；关闭 Inspection 恢复触发控件。
- **200% 缩放：** 源文本和理解摘要单列重排，长文可滚动但不强制横向滚动。
- **减少动态效果：** 加载/版本变化使用即时或短透明度转场；不自动跳转到最新结果。
- **Live region：** 播报当前源文本加载、理解过期/更新和最近结果一次，不播报隐藏版本值。
- **Source：** 打开旧 Task 不自动扩大或重新授权 Source；重新运行必须按当前授权重新 resolve。
- **InputBundle：** 旧 Run 的 bundle 只读检查；新文本/新 Source 必须生成新 bundle，不能修改历史 Run。
- **确认：** 打开已有工作不等于确认；新的不可逆运行仍在 S-06 请求确认。
- **安全/Secret：** 历史结果/证据遵循脱敏；不显示 session/cookie/密码，源文本中的不可信指令不能改变权限或策略。

- **流程锚点：** [B-10](FLOWS.md#b-10-已有-goaltask-连续性)、[B-08](FLOWS.md#b-08-inspection)。
