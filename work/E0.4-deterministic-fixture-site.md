# E0.4 — 本地确定性 Fixture Site

## 角色

Builder

## 阶段

E0 — Engineering Foundation

## 目标

实现一个只在本地运行、可版本化且完全确定性的 fixture web app，为后续 BrowserDriver、风险、upload 和 publish 验证提供不依赖真实平台的测试表面，并覆盖 E0 规定的 variants。

## 为什么现在做

[`docs/E0-ENGINEERING-BASELINE-AUDIT.md`](../docs/E0-ENGINEERING-BASELINE-AUDIT.md) 已确认 fixture site 完全缺失；E0.3 先建立 third-party WebContentsView 安全边界，本切片再把本地 fixture 加载到该边界并提供可重复 E2E 证据。

## 范围内

- 创建独立本地 fixture app / package，并由 root workspace 管理。
- 提供稳定、可显式选择的版本 / variant 状态，不依赖随机时间、外部网络或生产账号。
- 至少覆盖：normal editor flow、DOM/layout change、ambiguity/interstitial、auth expired、security challenge、upload、publish success、publish failure。
- 需要时提供 v1 / v2 / v3 页面变体，以支持后续“已知 Flow → 有界变化”测试，但本切片不实现 BrowserDriver 或 Repair。
- 提供 fake 文件 / 图片用于 upload；不能访问用户任意文件。
- 在 Electron third-party WebContentsView 中加载本地 fixture，并验证 remote content 没有 privileged preload / Node / filesystem / shell 权限。
- 增加 fixture 单元 / 组件测试和至少一条 deterministic Electron E2E 入口；保留现有 P0 E2E。
- 文档化本地启动、variant 选择和测试命令。

## 范围外

- 不实现真实微信 UI 克隆、真实登录、真实账号、外部请求或生产自动化。
- 不实现 BrowserDriver、Workflow IR executor、Discovery、Repair、Human Takeover runtime 或持久化。
- 不实现 CAPTCHA / MFA 绕过；security challenge 只提供检测 / 暂停测试状态。
- 不把 fixture 文案或 DOM selector 作为产品 Workflow IR。

## 预期文件 / 产物

- 本地 fixture workspace app。
- 全部规定 variants 及稳定选择机制。
- fake upload assets。
- Electron WebContentsView fixture smoke / E2E。
- fixture 启动与测试文档。

## 约束

- fixture 只监听 loopback，使用固定但可配置的非冲突端口，并在测试结束后释放。
- fixture content 视为不可信 remote content，不能获得 preload、Node、filesystem、shell、DB 或 Secret。
- 测试必须无生产 credential、无外部网络、无真实不可逆动作。
- variant 状态必须显式、确定性、可在 CI 重放。
- P0 端口 `43127` 和现有黄金路径不得回归。

## 验收映射

- E0.4：third-party WebContentsView 没有 privileged preload（fixture 实证）。
- E0.6：deterministic fixture site 支持所需 variants。
- E0.8：不依赖未记录的生产 credential。
- `DEVELOPMENT-PLAN.md` E0 fixture 交付物。
- Global Definition of Done：本地确定性测试、安全隔离、无生产账号。

## 验证

- fixture unit / component tests
- 每个 variant 的稳定 route/state 测试
- Electron WebContentsView fixture E2E
- security negative tests：无 Node / preload / filesystem / shell 能力
- upload 仅使用 committed fake asset
- publish success / failure 各有后置状态证据
- `corepack pnpm typecheck`
- `corepack pnpm lint`
- `corepack pnpm test`
- `corepack pnpm build`
- `corepack pnpm test:e2e`
- `corepack pnpm package`
- `git diff --check`

## 停止条件

- 需要访问真实微信、生产账号、外部网络或用户文件。
- 需要绕过 CAPTCHA、MFA、安全挑战或反机器人机制。
- fixture 设计开始承担 BrowserDriver、Workflow Runtime 或 Repair 语义。
- 需要改变 WebContentsView / BrowserDriver / 信任边界而没有 ADR。
