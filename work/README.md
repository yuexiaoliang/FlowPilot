# Work Packets

This folder may contain bounded, currently useful agent assignments.

These files are **execution aids**, not canonical product/architecture truth.

Canonical authority remains:
- AGENTS.md
- docs/PROJECT-STATE.md
- docs/DEVELOPMENT-PLAN.md
- docs/ACCEPTANCE.md
- accepted ADRs and relevant canonical docs

Rules:
- one packet = one bounded reviewable slice
- packets must cite canonical acceptance criteria
- packets may be deleted/archived after completion if PROJECT-STATE and Git history preserve current truth
- do not build a second roadmap here
- do not use packets to weaken acceptance criteria

A maintainer can assign a packet by saying:

> Implement the task packet at work/<file>. Follow AGENTS.md, validate it, update project state if appropriate, and leave a handoff.
