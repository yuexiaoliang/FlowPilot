# E0.3 — Desktop Shell、typed IPC 与安全边界

## 角色

Builder

## 阶段

E0 — Engineering Foundation

## 目标

在不扩展产品行为的前提下，建立 Electron main / preload / renderer 的最小 typed IPC skeleton，并为可信 Renderer 与未来 third-party WebContentsView 建立可自动验证的安全默认值。

## 为什么现在做

[`docs/E0-ENGINEERING-BASELINE-AUDIT.md`](../docs/E0-ENGINEERING-BASELINE-AUDIT.md) 已确认当前 trusted Renderer 的 Node/context isolation/sandbox 基线有效，但 preload、IPC contracts 和 third-party WebContentsView 边界缺失。E0.2 先提供一致工具链和 CI，本切片在其上补齐 E0 Acceptance 1–4。

## 范围内

- 创建最小 `ipc-contracts` 边界，定义明确 channel、request/result 与可序列化 error 类型。
- 创建 sandbox-compatible preload，通过 `contextBridge` 只暴露当前 shell 真正需要的最小 typed API。
- main handler 对 incoming payload 做运行时校验；不暴露任意 channel、文件路径、shell、process、database 或 `webContents`。
- 为 Renderer 提供声明合并 / 类型入口，确保 provider 实现类型不泄漏到 UI。
- 把可信 Renderer 与 third-party WebContentsView 的 webPreferences / session / navigation / permission 默认值拆成可测试的小型纯配置。
- 建立 third-party WebContentsView 安全壳的最小实现或契约证据：无 privileged preload、Node off、context isolation / sandbox / webSecurity on、导航与 popup 受控。
- 增加 IPC 契约、安全配置和 Electron smoke / integration 测试。

## 范围外

- 不实现 BrowserDriver、CDP 自动化、真实平台 adapter、账号 session、Source、SQLite、worker 或 fixture variants。
- 不给 remote content 暴露 preload API。
- 不增加通用 `invoke(channel, payload)`、任意文件系统访问或任意代码执行。
- 不改变 P0 UI 语义、D0 设计或端口。

## 预期文件 / 产物

- 最小 typed IPC contracts package / module。
- `apps/desktop/src/preload/` 与构建配置。
- main IPC handler 与 Renderer typed bridge。
- trusted / third-party webPreferences 和权限 / 导航策略测试。
- 必要的 Electron integration smoke。

## 约束

- Electron、React、WebContentsView 和信任边界保持 ADR-0001。
- 外部 / IPC payload 需 runtime schema validation；不得用 `any`。
- third-party WebContentsView 不使用 privileged preload，不能获得 Node / filesystem / shell / DB / Secret。
- 所有 handler 支持清晰 typed error；不做隐藏回退。
- 不把 platform/provider-specific 类型泄漏到 domain 或 renderer contract。

## 验收映射

- E0.1：Renderer 没有 Node integration。
- E0.2：context isolation 开启。
- E0.3：preload API 最小且 typed。
- E0.4：third-party WebContentsView 没有 privileged preload。
- Global Definition of Done：IPC runtime validation、安全、typed failure、架构边界。

- Electron dev / packaged smoke（不连接外部网络）
- `corepack pnpm build`

- `git diff --check`

## 停止条件

- 需要改变 Electron / WebContentsView / BrowserDriver / persistence 信任边界。
- 最小 API 需求存在实质产品歧义，无法从当前 shell / E0 Acceptance 推导。
- Electron 限制导致必须给 third-party content privileged preload。
- 需要真实外部网页、生产账号或网络才能证明安全边界。
