# E0.2 — 工具链、CI 与 Packaging 基线

## 角色

Builder

## 阶段

E0 — Engineering Foundation

## 目标

补齐可从 root 一致执行的 lint / format / package 工具链、GitHub Actions 和 Electron Forge packaging 基线，使 clean environment 能用固定 Node / pnpm 重复执行 E0 规定的工程命令。

## 为什么现在做

[`docs/E0-ENGINEERING-BASELINE-AUDIT.md`](../docs/E0-ENGINEERING-BASELINE-AUDIT.md) 已确认 strict TypeScript、Vitest、Playwright 和 P0 build 可用，但 `lint` / `package` 脚本、ESLint / Prettier、CI 和 packaging 均缺失。先固定命令与 CI，后续 IPC / fixture 切片才能在同一质量门禁上开发。

## 范围内

- 为 TypeScript / React / Electron 代码增加 ESLint 配置，并让 root `pnpm lint` 可重复执行。
- 增加 Prettier 配置和不修改文件的格式检查；格式写入命令如存在必须与检查命令区分。
- 增加 Electron Forge 的最小 packaging 配置和 root `pnpm package`。
- 增加 GitHub Actions，使用固定 Node / Corepack / pnpm 和 frozen lockfile，至少执行 typecheck、lint、test、build。
- 更新 root command 文档，区分已验证命令、package 输出和当前平台限制。
- 保留现有 P0 dev / build / test / E2E 行为与端口 `43127`。

## 范围外

- 不实现 preload、IPC、WebContentsView、fixture site、BrowserDriver、SQLite 或新产品行为。
- 不升级 Electron、React、Playwright、Vite 或 TypeScript major。
- 不加入 Turborepo / Nx / Docker 或发布服务。
- 不进行 code signing、自动发布或生产 credential 配置。

## 预期文件 / 产物

- root / desktop package scripts 与必要依赖。
- ESLint / Prettier 配置。
- Electron Forge packaging 配置。
- `.github/workflows/` 中的最小 CI。
- README / 开发文档中的完整 root commands。
- 与配置相关的最小测试或 smoke 证据。

## 约束

- 依赖使用固定版本并更新 `pnpm-lock.yaml`。
- CI 不连接生产账号或真实服务。
- packaging 不嵌入 `.env`、Secret、browser profile、auth state、数据库或测试结果。
- 不通过忽略现有错误来制造 lint / format PASS；必要排除项必须具体且有理由。

## 验收映射

- E0 clean-clone commands：`install`、`typecheck`、`lint`、`test`、`build`、`dev`。
- E0.5：CI 跑 typecheck / lint / test / build。
- E0.7：root commands 有准确文档。
- `DEVELOPMENT-PLAN.md` E0：ESLint + Prettier、GitHub Actions、`pnpm package`。
- Global Definition of Done：供应链、文档、自动验证。

## 验证

- `corepack pnpm install --frozen-lockfile`
- `corepack pnpm typecheck`
- `corepack pnpm lint`
- Prettier check 命令
- `corepack pnpm test`
- `corepack pnpm build`
- `corepack pnpm test:e2e`
- `corepack pnpm package`
- packaging 产物内容 / Secret 排除 smoke
- GitHub Actions YAML 静态校验
- `git diff --check`

## 停止条件

- Forge 需要偏离 ADR-0001 / `TECH-STACK.md`。
- packaging 需要 code signing、notarization 或发布 credential 才能本地验证。
- lint / format 需要大范围改写 P0 产品代码而不能保持行为不变。
- CI 方案需要生产账号、真实平台或未记录 Secret。
